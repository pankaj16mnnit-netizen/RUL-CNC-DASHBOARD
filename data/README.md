# Data

- `sample_upload.csv`: a demonstration upload with two machines. Machine 1 has its full history (261 cycles). Machine 2 has only 10 cycles, so the dashboard shows the short-history warning. It contains sensor and identifier columns only, with no labels, the same as a real upload.
- The full training dataset (`cnc_machining_centre_rul_dataset (2).csv`) is not committed here. Place it in this folder if you want to rerun the notebook from the repository.
